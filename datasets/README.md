# Calibration Data Notes

This repository only keeps small calibration assets locally.

## Included Here

- `checkerboard/left01.jpg` to `checkerboard/left05.jpg`
- `checkerboard/test.yaml`

These were recovered from the repo's pre-`refurbed` history because they are lightweight and still useful if you want to experiment with camera intrinsic calibration outside the main app flow.

## Not Included Here

I checked the common public gaze-estimation datasets and did not vendor them because they are too large for a repo like this:

- [MPIIGaze](https://www.collaborative-ai.org/publications/zhang18_pami.pdf)
- [GazeCapture](https://gazecapture.csail.mit.edu/cvpr2016_gazecapture.pdf)
- [ETH-XGaze](https://arxiv.org/abs/2007.15837)

Those are better treated as external research datasets, not checked-in project assets.
